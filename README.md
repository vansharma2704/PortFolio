# Vansh Sharma — Portfolio

An editorial developer portfolio built with Next.js, Tailwind CSS, Framer Motion, GSAP, and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Personal details, project copy, metrics, experience, social URLs, and lab experiments live in `data/portfolio.ts`. The included content is realistic demo data, not verified client work. Replace it with your own details and update the canonical domain in `app/layout.tsx`, `app/sitemap.ts`, and `app/robots.ts` before launch.
